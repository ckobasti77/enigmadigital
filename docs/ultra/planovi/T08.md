1. **Aeonik nema tabelarne cifre.** U `public/assets/fonts/aeonik/*.otf` GSUB tabela je prazna (jedina GPOS osobina je `kern`), a cifre su različite širine (Regular: „0" 617, „1" 318, „7" 512 jedinica). ### 1.2 Tokeni

```css
/* app/globals.css — :root, odmah posle bloka „Accent cyan" */
  /* ── Radnja — jedna boja primarne radnje (ULTRA P1, O5) ──────────────────
     Ista na svakom ekranu. Boja modula kaže „gde si", radnja kaže „šta da
     klikneš". Nose je: primarno dugme, dugme-veza, uključen Switch i
     Checkbox, okvir fokusa, uključen filter i aktivan jezičak.
     Izmereno (scripts/contrast-check.mjs): tamni tekst na radnji 9,67:1. */
  --radnja: var(--accent-400);                 /* #58c4ff */
  --radnja-hover: var(--accent-300);           /* #6ccbff — hover posvetljuje */
  --radnja-tekst: var(--text-inverse);         /* #091120 */
  --radnja-soft: color-mix(in oklab, var(--radnja) 14%, var(--surface));   /* #1d314a — izabrano */
  --radnja-line: color-mix(in oklch, var(--radnja) 45%, transparent);

  /* Neutralna podloga kontrole: sporedno dugme, hover obrisa i tihog
     dugmeta, istaknuta stavka menija i izbora. */
  --surface-control: color-mix(in oklab, var(--surface-raised) 92%, var(--text-primary));        /* #273348 */
  --surface-control-hover: color-mix(in oklab, var(--surface-raised) 86%, var(--text-primary));  /* #323e53 */
```

- **shadcn sloj (`:root`):** `--primary: var(--radnja)` i `--primary-foreground: var(--radnja-tekst)`. `--ring` ostaje `var(--focus-ring)`, a `--focus-ring-strong` ostaje `var(--accent-400)` (= `--radnja`). `--accent` se ne menja.
- **`[data-module]`:** brišu se tri reda (`--primary`, `--ring`, `--focus-ring-strong`) i rečenica komentara „Unutar modula shadcn sloj prati modul…". Ostaju `--mod-soft`, `--mod-line` i `--mod-glow`.
- **`@theme inline`:** dodaju se `--color-radnja`, `--color-radnja-hover`, `--color-radnja-tekst`, `--color-radnja-soft`, `--color-radnja-line`, `--color-surface-control` i `--color-surface-control-hover`. Briše se `--shadow-mod`, jer posle T09 nema upotreba (jedine su `focus-card.tsx:43` i `button.tsx:31`).
- Vrednosti `--mod-*` se ne menjaju; ostaju za mesto (prompt T09).
- Komentar na vrhu `globals.css` („Boja je informacija i ima četiri uloge") dobija šest uloga iz `DESIGN.md`.

### 7.1 API `components/ui/select.tsx` (nad `@base-ui/react/select` 1.7.0, bez novih paketa)

```tsx
export type SelectOption<V extends string = string> = { value: V; label: string; disabled?: boolean };
export type SelectOptionGroup<V extends string = string> = { label: string; options: readonly SelectOption<V>[] };

export function Select<V extends string>(props: {
  /** Ime izbora — obavezno. Bez `showLabel` ide u `aria-label` okidača. */
  label: string;
  /** Vidljiv natpis iznad okidača (`Select.Label`). Podrazumevano false. */
  showLabel?: boolean;
  value: V | null;
  onValueChange: (value: V) => void;
  options: readonly (SelectOption<V> | SelectOptionGroup<V>)[];
  /** Tekst kad ništa nije izabrano („Izaberi objavu"). */
  placeholder?: string;
  /** `sm`: 28 px (tabele, trake), `default`: 32 px; na dodir uvek ≥ 44 px. */
  size?: "sm" | "default";
  /** Za spoljni `<Label htmlFor>` (npr. `Field` iz `form-kit.tsx`). */
  id?: string;
  name?: string;
  required?: boolean;
  disabled?: boolean;
  invalid?: boolean;
  /** Širina okidača. */
  className?: string;
  /** Dodatak ispred natpisa u okidaču i stavci (npr. tačka temperature). */
  renderOption?: (option: SelectOption<V>) => ReactNode;
  /** Klasa okidača po izabranoj vrednosti (boja temperature u pregledu uvoza). */
  triggerClassName?: (value: V | null) => string | undefined;

// Delovi za posebne slučajeve, po shadcn obrascu:
export { SelectRoot, SelectTrigger, SelectValue, SelectContent, SelectItem, SelectGroupLabel, SelectSeparator };
```

**Ponašanje i izgled:**
- `Select.Root` dobija `items` (niz `{ value, label }`), pa `Select.Value` piše natpis, a ne sirovu vrednost. `modal={false}` (bez zaključavanja skrola). `onValueChange` ignoriše `null`.

  - `aria-invalid` se crta kao na polju.
  - Fokus je globalni okvir (radnja) plus `focus-visible:border-ring`.

### 10.5 Rizici

6. **Pregled uvoza:** 100 instanci `Select` (2 po redu × 50). Popup se ne montira dok je zatvoren. Ako je crtanje sporo, izbor temperature se crta tek kad red dobije fokus (ODLUKA T11).

### 10.6 Odluke ovog plana (za potvrdu; svaki korak ih prepisuje u svoje ODLUKE)
1. Imena tokena: `--radnja`, `--radnja-hover`, `--radnja-tekst`, `--radnja-soft`, `--radnja-line`, `--surface-control`, `--surface-control-hover`.
2. Hover primarnog dugmeta posvetljuje na `--accent-300`. Sjaja nema ni na primarnom dugmetu ni na fokus kartici.
3. `destructive` je tinta (`danger-soft`), i u potvrdi. Punog crvenog dugmeta nema.
4. Merači napretka su neutralni (`text-secondary` → `text-primary`), nisu ni boja radnje ni zlatna.
5. Neaktivne pločice modula (bočna traka, „Više", ⌘K) postaju neutralne u T09.
6. Izbor (uključen filter, aktivan jezičak, tekući korak, izabrana pilula) je u boji radnje. Segmenti (`ToggleGroup`, `SegmentedToggle`) ostaju neutralno podignuti.
7. `--text-muted` ide sa 0,80 na 0,86, umesto da se `-soft` podloge izblede.
8. `--temp-*-ink` na L 0,76 služi za tekst temperature. Blizina hladne boje i cijana čeka Interes (U4).
9. Aeonik nema `tnum`, pa `CountUp` rezerviše širinu, a brojčane kolone tabela ostaju mono.
10. Broj telefona se računa kao ID (mono je dozvoljen).
11. `Input` i `DropdownMenu` dobijaju 44 px na dodir, iako nisu na spisku §6.2 plana runa.
12. Mera u uredniku pravila prelazi sa `DropdownMenu` na `Select`.
13. Prilagođen period dobija tekstualna polja „27. 10. 2026." sa prečicama, bez kalendara. Ostala polja datuma čekaju U4 i U13.
14. Jezgro formata (`procenat`, `trajanje`) je u `convex/lib/formatJezgro.ts`, jer ga deli i server.
15. Trajanje se piše u h / min / s, bez nultih jedinica i bez sekundi od 1 h, sa NBSP između broja i jedinice. To važi i za dužinu videa.
16. `verify:ultra-format` pokriva i pravilo „nema izvornog `<select>`" (obe teme T11 u jednoj proveri).
17. U linku ili dugmetu `NazivMere` zamenjuje sestrinski `InfoMere`, pa nema ugnežđene interakcije.
18. Nazivi kanala dolaze iz jednog izvora (`INTEGRACIJA_NAZIV`), sa zatečenim imenima proizvoda („Meta Ads", „Google Ads").
19. Dugi rep boje modula (oko 700 upotreba) ostaje za U10–U16, pod plafonom.
